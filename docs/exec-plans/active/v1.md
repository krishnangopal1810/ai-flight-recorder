## Decisions

- Go core with native Python and TypeScript SDKs.
- REST/OpenAPI plus SSE; native OTLP HTTP/gRPC.
- SQLite/filesystem locally; PostgreSQL/S3-compatible storage when hosted.
- OCI isolation is mandatory for executable replay.
- Explicit framework-neutral boundary wrappers; no broad auto-patching in V1.
- Compose engine socket paths are daemon-native; client-context paths such as a Colima host forward must never be used as bind sources.
- Replay envelopes and candidate telemetry cross the OCI API through an isolated named volume and bounded tmpfs; client-local bind paths are forbidden because remote daemons cannot resolve them.
- The gateway image is operator-controlled configuration, not a replay-client input; an untrusted replay principal must not select the privileged policy-enforcement component.
- OCI application and evaluator runners use explicit image entrypoints and attach stdin because both public contracts are argv plus JSON stdin.
- Live gateway destinations resolve on an operator-selected OCI network; the gateway joins it only when the plan contains allowlisted live hosts.
- Imported compatible-minor capsules retain their original JSON document privately and merge only unknown members back during serialization; the typed current representation always wins for known fields. This is safe because stored capsules are immutable and preserves nested forward-compatible evidence without proliferating duplicate schema definitions.
- Evaluator span input and output use the operation's policy-processed payload references; only evaluator identity, version, score, and threshold are retained as metadata. Model configuration is associated from child LLM spans because standard instrumentation places it on the model operation rather than the root.
- Provenance uses observed values only. Standard resource facts and explicit `flight.*` facts are parsed into typed fields; absent or invalid prerequisites are named in `provenance.missing`, while an absent dirty digest means a clean worktree rather than missing evidence. Provenance comparisons use canonical JSON so nested maps and entrypoints produce deterministic evidence without nil-versus-empty noise.
- Content supplied as bytes and producer-reported omissions are mutually exclusive. Omission records carry normalized reason, size, media type, and an optional validated producer digest; bytes rejected before policy approval are never collector-hashed. Standard GenAI tool definitions use the same content-addressed policy path as operation payloads. Replay input is selected from the parentless root span, never from operation sequence position.
