# CLI reference

Generated by `flight help markdown`.

## `flight`

Reproduce and isolate AI agent failures

```text
flight [flags]
```

## `flight bisect`

Search Git revisions using controlled replay

```text
flight bisect [flags]
```

## `flight capsule`

List, inspect, import, and export Run Capsules

```text
flight capsule
```

## `flight capsule completeness`

Report playback, replay, diff, and bisect prerequisites

```text
flight capsule completeness <capsule-id>
```

## `flight capsule export`

Export a portable capsule bundle

```text
flight capsule export <capsule-id> <file.tar.zst>
```

## `flight capsule import`

Import and verify a capsule bundle

```text
flight capsule import <file.tar.zst>
```

## `flight capsule list`

List capsules

```text
flight capsule list [flags]
```

## `flight capsule show`

Show and verify a capsule

```text
flight capsule show <capsule-id>
```

## `flight completion`

Generate the autocompletion script for the specified shell

```text
flight completion
```

## `flight completion bash`

Generate the autocompletion script for bash

```text
flight completion bash
```

## `flight completion fish`

Generate the autocompletion script for fish

```text
flight completion fish [flags]
```

## `flight completion powershell`

Generate the autocompletion script for powershell

```text
flight completion powershell [flags]
```

## `flight completion zsh`

Generate the autocompletion script for zsh

```text
flight completion zsh [flags]
```

## `flight demo`

Manage deterministic local evidence fixtures

```text
flight demo
```

## `flight demo seed`

Record baseline and divergent demo capsules

```text
flight demo seed
```

## `flight demo seed-incomplete`

Record a capsule with one missing tool response

```text
flight demo seed-incomplete
```

## `flight demo seed-sensitive`

Record policy-redacted evidence and one safe quarantine diagnostic

```text
flight demo seed-sensitive
```

## `flight diff`

Find the first meaningful divergence

```text
flight diff <baseline-capsule> <candidate-capsule>
```

## `flight evaluator`

Validate and execute versioned incident evaluators

```text
flight evaluator
```

## `flight evaluator export`

Export a versioned evaluator for local or CI execution

```text
flight evaluator export <evaluator-id> <file> [flags]
```

## `flight evaluator run`

Run an evaluator in an isolated OCI container

```text
flight evaluator run <definition.yaml> [flags]
```

## `flight evaluator runs`

List persisted evaluator evidence

```text
flight evaluator runs <capsule-id>
```

## `flight evaluator validate`

Validate an evaluator definition

```text
flight evaluator validate <definition.yaml>
```

## `flight help`

Help about any command

```text
flight help [command]
```

## `flight help`

Generate help artifacts

```text
flight help [flags]
```

## `flight help markdown`

Print CLI reference as Markdown

```text
flight help markdown [flags]
```

## `flight init`

Create a safe replay application definition

```text
flight init --project <id> [flags] -- <container-entrypoint argv...>
```

## `flight playback`

Render recorded evidence without execution

```text
flight playback <capsule-id>
```

## `flight record`

Run an application with Flight capture enabled

```text
flight record [flags] -- <application command>
```

## `flight replay`

Run an application under a recorded replay plan

```text
flight replay <capsule-id> [flags]
```

## `flight schema`

Manage public generated contracts

```text
flight schema
```

## `flight schema generate`

Generate checked-in schema references

```text
flight schema generate [flags]
```

## `flight serve`

Run the local or single-tenant service

```text
flight serve
```

## `flight token`

Manage scoped API tokens

```text
flight token
```

## `flight token create`

Create a token; its value is shown once

```text
flight token create <name> [flags]
```

## `flight token revoke`

Revoke a token by its non-secret ID

```text
flight token revoke <token-id>
```

## `flight version`

Show CLI, release, and schema versions

```text
flight version
```
