# Golden principles

1. Evidence precedes explanation.
2. External data is parsed once at a typed boundary.
3. Privacy policy runs before persistence or observability.
4. Missing replay evidence blocks execution; it never enables a live fallback.
5. Infrastructure enters domains through explicit providers.
6. Shared invariants belong in shared packages, not copied helpers.
7. Every supported behavior has an agent-runnable deterministic test.
8. Repository-local documents and schemas are the source of truth.
9. Repeated implementation failure indicates a missing harness capability.
10. Safety, integrity, and compatibility checks are blocking.
