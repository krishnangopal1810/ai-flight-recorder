# Frontend

The inspector is a read-oriented React application using only the generated OpenAPI client. Its supported routes cover capsule discovery, playback, completeness, job progress, and divergence evidence. Evaluator authoring and bisect control remain CLI-first.

Use semantic HTML, accessible roles, stable `data-testid` attributes only where roles are insufficient, and deterministic seeded data. Playwright captures DOM snapshots, screenshots, and video for critical journeys.
