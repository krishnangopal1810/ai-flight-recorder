# Community guide

GitHub Discussions is the project’s long-form community surface:

- **Welcome** — introductions, onboarding questions, and project orientation.
- **Show and Tell** — integrations, regression suites, and investigation workflows.
- **Incident Stories** — sanitized failures that were hard to reproduce and the evidence that was missing.
- **Roadmap** — proposals tied to a concrete user outcome and acceptance proof.

Keep credentials, production identifiers, customer content, and capsule payloads out of public posts. Vulnerabilities use the [private security process](../../SECURITY.md). Reproducible product gaps use the focused issue forms.
