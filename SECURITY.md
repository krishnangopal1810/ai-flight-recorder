# Security policy

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/krishnangopal1810/ai-flight-recorder/security/advisories/new). **Do not open a public issue for a suspected vulnerability.**

Include the affected version or commit, impact, prerequisites, reproduction steps, and any suggested mitigation. Never include real customer prompts, credentials, capsule payloads, or production identifiers.

## Supported versions

| Version | Security fixes |
|---|---|
| Latest public alpha | Supported on a best-effort pre-1.0 basis |
| Older alphas and unreleased commits | Upgrade to the latest alpha or `main` |

We aim to acknowledge a report within three business days. Triage, remediation, disclosure timing, and credit will be coordinated with the reporter. Pre-1.0 interfaces may change when a safe fix requires it.

For the product's security model, trust boundaries, replay isolation, and capture-policy invariants, read [docs/SECURITY.md](docs/SECURITY.md).
